# 报告交付前的证据核对

每项标为「通过」「待补充」或「不适用」，记录核对人及日期。不要用报告长度或引用数量代替质量检查。

| 检查项 | 通过条件 |
|---|---|
| 来源可打开 | 关键链接能访问，标题、作者、年份与正文一致 |
| 版本与时间 | 论文版本、软件版本、定价日期和研究截止日期明确 |
| 结论有依据 | 每条重要主张能定位到支持它的原文段落、图或表 |
| 证据强度 | 区分官方原始资料、二手报道、评论与推断 |
| 指标可比较 | 使用相同数据划分、指标协议与输入条件；否则说明不可直接比较 |
| 数值身份明确 | 文献报告、第三方复现、本地实测与估计分别标注 |
| 可复现入口 | 代码、权重、数据和许可证的实际可用性经过核对 |
| 反证未遗漏 | 记录与结论冲突的资料及未解决的问题 |
| 商业假设 | 公开资料不能证明真实付费意愿；访谈和原型实验仍待执行 |
| 权利与隐私 | 只使用有权处理的文档，不把未授权内部资料发送给外部模型 |
| 输出完整 | 来源清单、已知限制、人工下一步齐全 |

报告中不确定的内容保留「未确认」，不能为了让结果好看而补写引用、实验或市场数值。
